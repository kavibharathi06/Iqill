# InterQill

Resume-Based Interview Practice and Skill Gap Analyzer

## Overview

InterQill is an NLP-based interview preparation system.

The user uploads a resume.

The application:

* Extracts text from resume
* Cleans and preprocesses text
* Extracts skills
* Generates interview questions
* Evaluates candidate answers
* Calculates technical and communication score
* Detects skill gaps

## Features

* Resume Parsing
* Skill Extraction
* Question Generation
* Sequential Interview Experience
* Answer Evaluation
* Skill Gap Detection
* Score Analytics

## Tech Stack

Python
Streamlit
NLTK
Pandas
Scikit-learn
TF-IDF
Cosine Similarity

## Workflow

Resume Upload
→ Text Extraction
→ Preprocessing
→ Skill Extraction
→ Question Generation
→ Candidate Answer
→ Evaluation
→ Final Report

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
